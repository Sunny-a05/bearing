# Library Index

Catalog of everything archived (not deleted) via the dock's `library/` outcome. See
`os/dock/DOCK.md` for the pipeline and the two-tier memory model.

The library is the reversible default: material that is real but not (yet) worth a
full wiki page lands here with a thin digest beside it. **Nothing here is ever
deleted** — an item that turns out to matter is enriched and promoted into `raw/`
plus a wiki page.

**Format:** `- [filename](digest-yaml-path) — one-line gist. tier: thin|rich. tags: [registry-cards]. dropped: YYYY-MM-DD.`
